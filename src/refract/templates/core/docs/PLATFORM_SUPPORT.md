## Portable Core

All selected platforms share provider-neutral project instructions, task workflow, ADRs, deterministic validators, and Agent Skills. Each capability is rendered in the platform's native format; a capability a platform cannot express is listed as Unsupported above. The project-scoped `refract` skill is advisory: it stops after preview and requires separate human-terminal apply.

All generated configuration is project-scoped. Agents must not install skills, agents, hooks, or settings into user-level or global directories for this project.

## Optional Features

- MCP is generated only when explicitly selected.
- Specialized agents are generated only when explicitly selected.
- Repository-hosting workflows and Git hooks are opt-in.
- Hooks never invoke an LLM or perform bootstrap mutation.
- The security-audit skill is documented but never generated or auto-installed; install it on demand per `docs/SECURITY_AUDIT.md`.
- The planning-and-task-breakdown and create-tickets skills are documented but never generated or auto-installed; install them on demand per `docs/TASK_BREAKDOWN.md`.
- Agent hooks (with hooks selected) run only the deterministic project validator and report results; they never invoke an LLM.
- Pi is deprecated; it consumes only the portable core.
